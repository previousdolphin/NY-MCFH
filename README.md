# NY Metro Coalition for Higher Ed

Source for nymetrocoalition.org.

- Branch `main`: the original static site, served by GitHub Pages.
- Branch `cms`: the Cloudflare Worker that renders the site and provides the editor at
  `/studio` (drafts, preview, publish, schedule, history).

Start with `docs/runbook.md` (operating it) and `docs/editor-guide.md` (using it).
Vocabulary used in the editor is in `docs/GLOSSARY.md`.
